The icon was supplied by the project owner, who confirmed on 2026-10-13 that they created it with AI tools for HAM and explicitly approved `GPL-3.0-only` for the original and generated variants. The repository contains the approved source image and generated Android/Play-sized derivatives. PNG metadata inspection found no embedded author, location, or license fields. No third-party artwork source was identified in the project files. Because tool-specific terms and the copyright status of AI-assisted material can vary, recheck any underlying tool terms before store submission.

The resolved `stableFdroidReleaseRuntimeClasspath` and Gradle catalog were reviewed on 2026-10-13. The principal runtime families are AndroidX/Compose/Lifecycle (Apache-2.0), Kotlin standard library and coroutines (Apache-2.0), OkHttp/Okio (Apache-2.0), and annotation/marker dependencies from JetBrains, JSpecify, and Guava (Apache-2.0). JUnit 4 is a test dependency, not an app runtime dependency, and retains its own license. License declarations were checked against cached dependency POMs where available and upstream project license files; no known nonfree runtime library was found. This is not a final binary/software-bill-of-materials review: re-resolve exact release artifacts, notices, dependency licenses, and F-Droid buildability before submission.
