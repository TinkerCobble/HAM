# Security reports

Please report suspected HAM vulnerabilities privately to
[support@tinkercobble.com](mailto:support@tinkercobble.com). Incoming mail to
this address was verified by an owner-controlled test; outbound automated mail
is not required for receiving reports.

Describe the affected HAM version, Android version, steps to reproduce, and the
result you expected. Do not post passwords, authorization tokens, Home Assistant
addresses, personal calendar screenshots, or other private data in public issues.
If a private sample is necessary, ask first how to share it safely.

There is no promised response time. Public discussion can follow after the
private report has been reviewed and sensitive details have been removed.
